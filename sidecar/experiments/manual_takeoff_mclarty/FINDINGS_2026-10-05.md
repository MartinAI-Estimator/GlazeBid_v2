# McLarty Mazda manual takeoff — findings for auto-takeoff
*2026-10-05 · Blind takeoff by Claude on the 35-sheet "Orig Plans" set, then compared with Martin's 12-sheet marked bid set (428 markups). Artifact: "McLarty Mazda Takeoff". Second test after Valvoline.*

## Result
- **86 of 91** scope objects Martin marked were found blind (94.5%): all 16 exterior frames (1–8, 24–26, 30–32), all 6 exterior glazing-only items (vision lites 9/12/16/22/29, HM window 21), interior storefront 100/101/102, interior glazing-only 118–121, all 24 frameless openings (103–106, 110–113, 131–145), the closure-trim break metal, note 10, the A2.0 legend rows, all 15 detail titles.
- **0** false scope.
- Sizes: every elevation Area within ~1" of Martin's (e.g. 4: 22'-11.1" vs 22'-11 1/16"; 2: 20'-0.9" vs 20'-0 15/16"). One size error in the blind run (type 1 at 12'-3" instead of 14'-4½") caused by a rounding bug, found by the comparison.
- **Misses (5):** A3.1 interior finish legend rows SF-3 and D-8; A3.0 finish note 13 (frameless hardware polished aluminum); SSG caulk joint count (76); polished edge count (58).
- **Partial:** frost film carried as one implied item, Martin measures it as an Area on all 24 openings; all-glass door count (8) in descriptions, not as count symbols; plan Polylengths not drawn (tag hexagons only).
- **Classification:** one difference — type 8 (TMW 450 door frame): Martin Ext SF, I Ext CW by legend. Every other TMW 450 frame he also called Ext CW.
- **Mine only (defensible):** bi-fold pairs at 1/3/5 as pass-thru; 6 mirrors flagged; GF-1 film at type 3; 24 ga sill flashing flagged; notes 12 + general hardware; RFIs (24–26 width 8'-0" vs 7'-0", narrow vs medium stile, film naming); red exclusions on OH/Rytec/grilles; details on A5.4–A5.9, A5.13, A6.1 (outside his set).

## How it was done (all text + vector geometry, no vision model)
1. **Sheet index** from the title block (sheet number = largest text in the lower-right block; title from the "Sheet Title" box). 35 sheets, no rotation on this set.
2. **Pictorial door & frame schedules first (A3.2 exterior, A3.3 interior).** No storefront schedule on this job. Each type = circled mark + "FROM/BETWEEN …" description + hardware table + a ¼"-scale drawing. Reader: find mark tokens → description lines in the column → `type_frames()` snaps the frame rectangle sitting on the floor line above the label (closed rect from long vertical/horizontal line pairs; stacked rects for transoms) → W×H at 18 pt/ft → bays/rows from mullion line clusters → dimension strings as a cross-check.
3. **Legend on A2.0** (SF-1 "curtain wall" = TMW 450, SF-2 "storefront" = TMS 114, GF-1 film, D-1…D-6 doors) parsed as rows; class follows the legend and is flagged where trade usage disagrees.
4. **Plan tags on A1.2** found by text token + enclosing vector hexagon (6 or 5 line segments). This separates door marks 100–147 from room numbers 100–134 (rectangles) and revision triangles (3 lines). 82 tags, each once.
5. **Elevation snap on A2.0:** for each hexagon tag, candidate rectangles within ±400 pt scored against the schedule W×H (height weighted ×2, penalty if the tag centre is outside); adjacent rects unioned for frames split by a column; stacked rect for the 12' upper frames. Scale ⅛" (9 pt/ft) confirmed by type 4 = 22'-11".
6. **Details:** titles are generic ("PLAN DETAIL", "WALL SECTION"); content found by keyword search inside each detail's region (title column, bounded by neighbouring titles). 70 titles/callouts on 19 sheets.
7. **Trade rules** decided every in/out (OH-door and Rytec glass out, HM lites glazing-only, frameless = all glass + film, bi-fold = pass-thru, closure trim matching storefront = ours, 24 ga sill flashing = flag).

## Bugs found (fixed in the experiment code; port to the sidecar)
- **Feet-inch formatter rounding:** 13.999' printed as `13'-12.0"`, parsed back as 12'-0" → elevation matcher picked the wrong rectangle at type 1 and raised a false RFI. Fix: carry 12.0" to the next foot. Lesson: never round-trip sizes through strings; keep inches as numbers.
- **Detail region builder:** a title to the right was treated as "above" and truncated the region (detail 6/A4.2 lost its STOREFRONT callout). Fix: only titles overlapping the detail's own column count as above.
- **Clipped lines:** the first `long_lines()` dropped any line not fully inside the search window, so ground lines and long sills never closed a rectangle (types 5, 6a, 24–26 failed). Fix: clip lines to the window instead of requiring containment.
- **Text vs geometry:** type 21 described as "4 lites" from a stray "(4 EQUAL PANELS)" string; mullion count said 3 (Martin drew 3). Rule: when a dimension string and the vector count disagree, trust the geometry and flag.

## What Martin's markups taught about conventions on this job type
- Plan: tag hexagon highlight **plus a Polylength along the opening** with its length, per class (Ext SF / Ext CW / Int SF / All Glass Wall Polylength). "Hollow Metal" callout at the HM window.
- Schedule: whole type drawing + its **hardware table** in the system color; Length Measurements on 30/31a/31b/32; one Qty box ("3 Thus" at 24–26).
- Elevation: one Area per frame; 30/31a/31b merged into one 29'-0" Area.
- All-glass: Area per opening, **film band Area** (drawn with the Glass Handrail Area tool), **SSG Caulk Count** on every silicone joint, **Polished Edge Count** on every exposed edge, **All Glass Doors** count, Polylength on plan. This is the bulk of his 428 markups.
- Exclusions left blank (OH, Rytec, grilles, HM/louver doors). Interior finish legend rows (A3.1 SF-3, D-8) and finish note 13 (A3.0) colored All Glass.
